BALANCE FETCHING:
  addresses[] → BalancesProvider.getBalances$
    → address validation per platform
    → network routing via parseTokenId
    → module filtering by platform
    → parallel module fetching
    → 30s timeout & stale marking
    → error recovery with cache
    → BalancesResult { status, balances, errors }

  IBalance JSON → Balance object
    → Getter chains (total, free, reserved, locked, etc.)
    → Formatting (planck, tokens, fiat)
    → Lock/extra filtering based on flags
    → Final calculated amounts

TOKEN ID ENCODING:
  (networkId, address) → parseTokenId()
    → extract networkId, type, identifier
    → lookup network and token
    → hydrate Balance with token/network data
